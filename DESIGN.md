# Slasher Studio

A Windows workbench with three task surfaces: Search, Results, and Updates/PR Preview. The primary workflow is name search → typed TXT → merged Saluki CDB. Snapshot, name tables, Saluki path and output path stay visible on Search; candidate methods, limits and extra pools sit under collapsed Advanced options. Search also retains a source selector for Saluki exports. Controls use cool paper neutrals, a pine-green action color, and familiar desktop widgets. Publication controls are hidden; the task saves a local draft automatically.

Interactive states retain their size and alignment. An underline marks the current tab, a check mark identifies selected asset types, and pale green distinguishes the main action and selected results. Keyboard focus has a separate outline.
