# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop, portable x64 distribution.

## Users

An asset extractor moving a Call of Duty name-recovery workflow to a new computer.

## Product Purpose

Control one workflow: select a snapshot and name database, recover animation,
audio, material and image names with Slasher, save typed TXT, then automatically
merge CSV and convert it with cod-name-db NameIndex into Saluki CDB. Search can
pause and resume. Advanced methods stay inside the task. PR stays a local preview.

## Operating Context

The capture is an existing `.ids` / `.pools.txt` pair. Modern audio alias captures can have a companion full-width key list. A Saluki installation folder or `hash_pkg` can supply the local names to preserve when exporting. The search is local; GitHub access is separate.
